# Privacy

Public source contains code, neutral examples, and synthetic fixtures. It excludes user persona files, private chats, databases/WALs, credentials, access tokens, screenshots, real workstation paths, account numbers, and private development journals. Historical repository objects are not copied into this release's fresh history.

At runtime, the library and snapshots are private user data. Raw text remains unchanged; optional structured views mask common credential fields and label normalization/omission. This is not a guarantee that every secret is detected. Hidden reasoning and binary carriers are not converted into textual experiences. Paths or links in reports may themselves be sensitive.

The management service is loopback-only with token protection; do not publish it as a public web service. Model configuration stores an environment-variable name for independent API credentials rather than a literal key. User-authorized model calls can transmit selected memory material to that configured provider; local embeddings use the specified loopback service.

Fading never automatically deletes raw sources. Explicit deletion updates dependent records and leaves non-content idempotency tombstones to prevent accidental resurrection, but does not delete host logs or old backups. No automatic recording of all desktop activity, microphone audio, or full multimedia carriers is enabled by this package.
