# Working memory and checkpoint execution

Manual lookup keeps the existing hybrid ranking. Automatic working memory examines up to 24 ranked passages before filling its smaller card budget. It compares query words, their co-occurrence within candidate records, identifying codes and the semantic lead over alternatives. A shared project name often occurs in several competing memories. An additional match that singles out the requested subject carries more weight. The existing source, correction, score and character limits still apply. Narrow queries may yield no automatic card; originals remain accessible through lookup and read.

A fresh user request to resume work can select a single open checkpoint from explicit task identity or relevant source links. Ordinary status questions and unresolved choices do not arm execution. During an inquiry a checkpoint's declared external writer cannot inherit authorization from historical text. A checkpoint may name its intended host tool with the optional `value.next_tool` field. A legacy checkpoint may instead use a tool explicitly named by the current user or a sourced actionable next step. Hosts with the normal turn-stopping hook can issue one internal reminder inside the same turn. A reminder makes no direct tool call and leaves host permissions in force.

The journal links attempts to their library, checkpoint version, session, tool, call ID and normalized argument digest. An identical operation for the same revision is blocked after success or an unknown outcome. A host-confirmed preflight refusal or a human decision that the operation did not apply permits a fresh attempt. A receipt-linked step needs a matching successful native result source before it can be marked done. An operation returning successfully alone does not certify a file or a remote effect; use an independent artifact, receipt or read-back appropriate to the task. Free-text requests, ambiguous scope, language coverage and retrieval remain finite. Manual lookup and explicit checkpoint selection remain available.
