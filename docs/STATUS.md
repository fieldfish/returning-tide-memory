# Scope and limits

Implemented: source archival, local hybrid retrieval, versioned state/situations, triggered bounded working memory, source-adjacent scenes, attributed fading/reinforcement, checkpoints, explicit owner handoff, uncertain-action recovery, structured activity views, local management, and consistent snapshots.

Not promised: infinite native context, perfect recall, subjective personality preservation, automatic full player observation, complete image/audio/video archives, every external action exactly once, or indefinite unattended uptime. ANN/BM25, automatic utility attribution, partitioned archival, and broader host compatibility remain future engineering choices.
