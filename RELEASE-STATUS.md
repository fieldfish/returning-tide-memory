# Status: Completed

Version 0.3.11 repairs false recovery holds in global and standard desktop tool scopes and adds an explicit read-mode contract for third-party plugins. The [recovery guide](docs/RECOVERY.md) describes which failures can be settled automatically, how to register a video inspector and how existing pending writes are reviewed.

Returning Tide Memory is a completed, stable release within the implemented scope described in docs/STATUS.md. It includes source archival, hybrid retrieval, contextual working memory, source-adjacent scenes, versioned state and situations, attributed fading, explicit handoffs, and recovery.

Validation is recorded in docs/VALIDATION.md and PACKAGE-STATUS.json. Completed describes delivery of these features; retrieval remains probabilistic and the documented operating limits still apply. Installation does not automatically bind an unrelated session or rewrite persona files.


## 0.3.7 change scope

This stage repairs known native no-effect tool refusals, foreground diagnostic metadata, actionable local human review and bounded evidence pagination. It does not claim that all historical feedback, arbitrary interruptions, third-party tool semantics, UI stalls or general contradiction adjudication are solved. Genuine unknown external effects remain subject to explicit review.


## 0.3.8 change scope

This stage addresses development reload/restart paths that lost a returned native result or produced a closed-database error from an old observer. Source-matched host successes can be recovered without replay. It does not silently clear genuinely unknown effects or historical failures, and does not claim all unrelated host stalls are fixed.

## 0.3.9 change scope

This is a test-only reliability hotfix for the idle-maintenance CI deadline exposed in 0.3.8. It uses a controlled clock, retains continuation checks, strengthens pause checks and bounds test-worker concurrency. The runtime is byte-for-byte unchanged from 0.3.8. No live session or local installation is changed by publishing this source.

## 0.3.10 change scope

Persistent lexical candidates, bounded idle maintenance, lifecycle-safe cancellation and an independently checked before/after benchmark are complete within the documented scope. Full current text remains authoritative for matches. Pending and oversized sources use exact verification. Semantic search still scans stored vector parts, and source/model budgets remain finite.
