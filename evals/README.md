# Evaluations

All bundled examples are synthetic. No private conversation or persona is bundled. Run recall, recall:dynamics, recall:situations, recall:activity, or recall:corrections with a local Ollama model. These measure candidates, source handling, and bounded context, not universal answer accuracy.

lookup-benchmark.mjs accepts an explicit independent baseline directory and generates temporary data; it never opens a live library. Corpus actor names were neutralized in 0.3.1. Old recorded narrative outputs are intentionally excluded rather than edited to imply they measured the renamed corpus.
